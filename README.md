# AD Photography Website

Portfolio and booking website for AD Photography (Ashim Dahal), live at https://adlightstudio.com.

- Static single-page site (`index.html`), deployed to Cloudflare Workers/Pages via direct upload.
- Booking inquiries are sent by email through Web3Forms.
- To update the live site: edit, then upload the new `index.html` as a new deployment in the Cloudflare dashboard (project "adlightstudio"). The custom domain stays attached.
