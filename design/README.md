# Website design source

The approved design for the five-page site (Home, Gallery, Pricing, About, Contact), each at desktop and phone width. Approved Nov 19, 2026.

- `canvas.json` lays out the boards. `Main.dc.html` is Home; `Book.dc.html` is Contact.
- `Mobile*.dc.html` files show each page at phone width by loading the desktop file with `mobile` on.
- `Nav.dc.html` and `Footer.dc.html` are the shared menu and footer.

These are design files from the design canvas, not the live site. Photos in them point to `/_blob/...` addresses that only exist inside that canvas tool, and they load `support.js` from the tool, so they won't render if opened straight from GitHub. The live site is the `site/` folder.

Changes made in code after approval: Drive event photos replaced the placeholders, the Gallery shows one sideways-scrolling row per session, the backgrounds have a light paper grain, and cards and photos sit on soft shadows.
