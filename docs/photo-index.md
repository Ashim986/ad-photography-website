## Adding a photo

1. Put a web-size copy (about 2500 px long edge, JPEG) in a Website exports subfolder.
2. Make 800, 1600 and full-size WebP copies named after what the photo shows, never a client name.
3. Add it to the right gallery row with plain alt text, check it is not used anywhere else, then add a line here.
